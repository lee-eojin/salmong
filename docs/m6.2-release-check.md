# M6.2: Release check

**Status: PENDING (box and laptop).** This file is the check plan. No row below has been run and no result is recorded here.

M6.2 makes the browser build a release: original shader art, sound effects, a mute control, licence files and a deploy job. This file starts with the art part (shader art v1). The sound, licence and hosted parts add their rows when their units land.

## Draw path

Shader art v1 adds no mesh, entity, material or draw call. The new quads go into the four `Layer` meshes and the one `ShapeMaterial`, so a frame is still 4 layer draws plus Bevy's full-screen draw: 5, limit 20. The fragment shader changed: `shapes.wesl` gained codes 4 to 9, every station and bus pixel runs new code, and one quad now covers the board. So the M5.2 frame gate must run again (row L1).

## Shader codes

A quad's code is in `uv.x = lx + 4 * code`. Codes 0 to 3 are unchanged, so passengers, the badge, the signs, the panel, the digits and the pending-edit line draw the same pixels as in M3.3.

| Code | Shape | Fragment rule |
|---|---|---|
| 0, 1, 2, 3 | circle, triangle, solid, star | unchanged |
| 4, 5, 6, 7 | circle, triangle, square, star with an ink band | `shape = code % 4`; distance `d` as for codes 0 to 3, and `max(abs(x), abs(y)) - 1` for the square. Ink where `d > -band[shape]`, the vertex colour inside |
| 8 | ring meter | annulus `0.80 < r < 1.0`; lit where `fract(atan2(x, y) / TAU)` is below the vertex alpha, so it fills clockwise from the top; the vertex colour, opaque |
| 9 | dot grid | from the world position `w`: `f = abs(fract(w + 0.5) - 0.5)`, a dot where `length(f) < 0.07`; the vertex colour |

The ink colour `#14213D` and the band widths (circle 0.24, triangle 0.20, square 0.24, star 0.14, in units of the quad's half size) are `ShapeMaterial` uniforms set from the Rust constants `INK` and `BAND`. The ring inner radius 0.80 and the dot radius 0.07 are constants in `shapes.wesl` and in `render.rs`; a test compares them. `render::shade` repeats the fragment rule on the CPU and `render::hit` uses it, so the expect files below come from the same rule.
