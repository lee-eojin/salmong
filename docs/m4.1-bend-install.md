# M4.1 Bend install review

Reviewed 2026-11-06 (KST). Upstream script `https://bend-lang.com/install.sh`, 99 lines, `VER="2.0.39"`, sha256 `d573d4d66de6a9b7e126bfc6f7184b459e5e1906cae58f96f74a637504525af2`.

**Decision.** The script was reviewed and not run. It cannot pin a version, so `scripts/install-bend.sh` downloads the release archive directly and checks it by sha256.

## Findings

1. Nothing unsafe. No sudo, no shell profile edits, nothing sent. One HTTPS download, checked by sha256 before extraction. `rm -rf` touches only fixed names under `${BEND_HOME:-$HOME/.bend}`.
2. It cannot pin. The URL serves the latest release, and the script is not in the repository at the tag. `bend update` runs an unverified `curl | sh` of the same URL.
3. Archive `bend-2.0.39-linux-x64.tar.gz`, 36,941,148 bytes, sha256 `6cf462fd8f70b094a4950ebb709a9c4ffd8f1d1189d9cedf1fd63cd5d041c7ab`. Tag `v2.0.39` is `a3efe8a`. Entries all sit under `bend/`, with no links or setuid.
4. `bin/bend` is an x86-64 ELF, 82,883,784 bytes, sha256 `2ec160fa4486d33aff51e9eedcc294d6b531dc10c279c00b0c00685dae2045cd`. `bend2/base.bend` sha256 `3cd0b0944b11e15c4da5c9af2560e3c04f27d3d37027f1617899aeec17b499ce` equals the tag's file.
5. No signature and no GitHub attestation. Nothing ties the binary to the source without a rebuild.
6. The version string proves little, because later source also prints `bend 2.0.39`. The pin is the sha256.
7. Telemetry: a daily `GET /check` after file runs, `guide` and `base`, stamped in `~/.bend/check.json`. Any non-empty `BEND_NO_TELEMETRY` skips it. The shim sets it, and `scripts/check-bend.sh` proves it with a control run against a closed local port.
8. `import 0x<hash>/...` and `import <name>@<version>/...` fetch from `BEND_HUB` whatever the telemetry setting. Repository Bend code uses `import Base` only.
9. The CLI keeps state under the home directory and finds `bend2/` from the real path of the binary, so the shim is safe.
10. `bend file.bend` with no `-o` runs in-process on the JS lane. It needs no clang and no system Bun or Node.
11. `IO.args()` starts with the program, so arguments start at index 1. `IO.print` appends a newline.

The plan's section 5 fact check read `4024f04`, after the tag. The facts M4 relies on hold at the tag (README L231, L238 to L240; WONTFIX L28, L54, L147).
